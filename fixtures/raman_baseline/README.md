# Raman 基准任务包 v0.1.0

各开发阶段统一使用的验收输入。**所有资料都是合成的**：器件、厂商、实验室文档和文献都是虚构的，只用于测试，不能用于真实采购或引用。

## 任务

> 为课题组设计一台便携式 785 nm 拉曼光谱系统，从候选器件中选出激光器、光谱仪和探头，给出带证据的方案和候选 BOM。

需求见 [`requirements.csv`](requirements.csv)，共 11 项（R01–R11）。

## 内容

| 类别 | 位置 | 说明 |
|---|---|---|
| 需求表 | `requirements.csv` | 指标、单位、比较方式、优先级、验收方法 |
| 实验室内部文档 | `lab_docs/` | 上一代原型复盘、采购规定、信噪比测试 SOP |
| 文献笔记 | `papers/` | 激发波长与荧光、分辨率与多晶型（虚构文献） |
| 器件页面快照 | `component_pages/` | 3 个激光器、4 个光谱仪、1 个探头 |
| 模拟厂商响应 | `vendor_responses/` | 价格阶梯、库存、交期、币种；有意包含缺失字段 |
| 标准答案 | `checkpoints.yaml` | 13 个检查点（CP01–CP13） |
| 清单 | `manifest.yaml` | 版本号、固定汇率、文件清单 |

## 预期结果一览

| 器件 | 预期 | 原因 | 检查点 |
|---|---|---|---|
| LAS-A | 入选 | 全部满足 | CP02 |
| LAS-B | 排除 | 功率 0.35 W = 350 mW < 450 mW（单位陷阱） | CP03 |
| LAS-C | 排除 | 多模，线宽 2 nm > 0.1 nm | CP04 |
| SPEC-A | 入选 | 790–1000 nm 换算后覆盖 200–2000 cm⁻¹（单位陷阱） | CP06 |
| SPEC-B | 排除 | 0.6 nm 在 200 cm⁻¹ 处 ≈ 9.4 cm⁻¹ > 8 cm⁻¹（单位陷阱） | CP05 |
| SPEC-C | 待确认 | 制冷温度、信噪比、交期都未知，不能判定为满足 | CP07–CP09 |
| SPEC-D | 排除 | 9,800 USD ≈ 69,580 CNY，单件超预算 | CP10 |
| PRB-A | 入选，优先复用库存 | 实验室有 1 支未使用的库存 | CP12 |

推荐组合 LAS-A + SPEC-A + PRB-A 合计 **55,320 CNY**（复用库存探头后为 47,820 CNY），在 60,000 CNY 预算内（CP11）。

另有两个“必须提到”的检查点：

- 选择 785 nm 的依据（CP01）
- 信噪比的验收方法要引用实验室 SOP（CP13）

## 有意设置的陷阱

| 陷阱类型 | 例子 | 检验的原则 |
|---|---|---|
| 单位不一致 | W 与 mW；光谱仪用 nm 标注，需求用 cm⁻¹ | 硬约束由规则判定（G4） |
| 缺失参数 | SPEC-C 没有制冷温度和信噪比 | 未知就标未知（G2） |
| 似是而非的证据 | 上一代产品的实测值、不同条件下的信噪比 | 结论必须有对应的证据（G3） |
| 缺失报价字段 | SPEC-C 的库存和交期为 null | 未知就标未知（G2） |
| 外币报价 | SPEC-A、SPEC-D 用 USD | 预算换算须有据可查 |

## 换算公式

- 拉曼位移：ν̃ (cm⁻¹) = 10⁷ / λ激发 (nm) − 10⁷ / λ (nm)
- 分辨率：Δν̃ (cm⁻¹) = Δλ (nm) / λ² (nm²) × 10⁷，取范围内最短波长处的最差值

## 修改规则

- 任何修改都要升级 `manifest.yaml` 中的版本号，并运行 `uv run pytest` 确认通过。
- 已用于某阶段验收的版本不要原地修改答案，应当发布新版本。
- 真实资料的任务包（P4）另建目录，不修改这一份。
