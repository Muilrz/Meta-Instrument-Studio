# 【合成资料】2025 年便携拉曼原型项目复盘

> 本文件为 MIS 基准任务包的**虚构**实验室内部文档，用于测试，不对应任何真实项目。

- 文档编号：LAB-2025-017
- 撰写：课题组仪器小组
- 日期：2025-12-10

## 1. 项目概况

2025 年用 532 nm 激发搭建了一台便携拉曼原型，用于生物样品和聚合物鉴别。

## 2. 主要问题

1. **荧光背景严重**。生物样品在 532 nm 激发下荧光背景很强，弱拉曼峰几乎被淹没。下一代应改用 785 nm 激发。
2. **长积分时噪声大**。光谱仪探测器没有制冷，积分超过 2 s 后暗噪声明显上升。下一代应选择 TE 制冷探测器，制冷到 -10 °C 或更低。
3. **接口不统一**。激光器用 FC/PC，探头用 SMA905，中间加了转接件，耦合效率损失约 15%。下一代三者统一用 SMA905。

## 3. 可以沿用的经验

- 同厂商（Vendor Gamma 光谱，虚构）上一代光谱仪的 Python SDK 好用，在 Windows 下集成只用了两天。
- 在 300 mW 激发、积分 1 s 的条件下，环己烷 802 cm⁻¹ 峰实测信噪比约 650:1，满足当时 500:1 的要求。

## 4. 库存

- 项目结束后剩余 **1 支 PRB-A 785 nm 拉曼探头**（SMA905 接口，未使用，存放在 B214 柜）。新项目可以直接复用。
