# 【合成资料】拉曼系统信噪比测试 SOP

> 本文件为 MIS 基准任务包的**虚构**实验室内部文档，用于测试。

- 文档编号：LAB-SOP-011

## 测试条件

- 样品：分析纯环己烷，石英比色皿
- 激发：785 nm，样品处功率 300 mW
- 积分时间：1 s，单次采集，不做平均

## 计算方法

1. 信号 S：802 cm⁻¹ 峰高减去基线（基线取 760–780 cm⁻¹ 平均值）。
2. 噪声 N：在 1900–2000 cm⁻¹ 无峰区间，取 10 次重复采集同一像素读数的标准差，再对区间内像素取平均。
3. 信噪比 = S / N。

## 判定

信噪比 ≥ 500 为合格。厂商宣称的信噪比如果测试条件不同（如“满量程信号下”），**不能直接用来判定**，须注明条件不一致。
